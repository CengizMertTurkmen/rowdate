Rowdate

Guide

Five minutes from install to your first synced event.

1. Open Rowdate

In your sheet choose Extensions › Rowdate › Open Rowdate. Row 1 must hold column names, for example Client, Date, Time, Duration.

2. Pick the calendar

The list shows every calendar you can add events to, including shared ones.

3. Match the columns

  • Event title is a template. Use + Insert column to build titles like {{Client}} · {{Service}}.
  • Date column is required. Real dates, formula results and text like 2026-11-10, 10.11.2026 or 11/10/2026 all work. Slashes follow your spreadsheet's locale (File › Settings).
  • Time is optional. Without it, events are all-day. A date cell that includes a time also works.
  • Duration in minutes (90), hours (1.5 h) or 1:30. Default 60 minutes. Or use an End date / End time column instead.
  • More fields: location, description (a template too), guest emails (comma separated), colour (1–11 or a name like blue, tomato), repeat (daily, weekly, monthly, yearly or a full RRULE:) with an optional repeat count, reminder minutes.
  • Cancel column: write yes, x or tick a checkbox to delete that row's event on the next sync.

The preview shows the first row as an event. If something is off, it says what.

4. Sync

Sync all rows or select rows first and use Sync selected rows. Rowdate adds two columns, Rowdate Event ID and Rowdate Status. Don't edit the ID column: it links the row to its event. Rows that did not change are skipped next time.

Live sync (Pro)

Tick Live sync and every edit you make on that sheet updates the event within seconds. Changes made by formulas or other people's scripts don't trigger it; run a normal sync for those.

Common messages

  • Date not recognised: the cell isn't a date Rowdate can read. Format the column as a date, or use 2026-11-10.
  • End is before start: check the end time or duration.
  • You cannot write to this calendar: ask its owner for "Make changes to events" access, or pick another calendar.
  • Event not found in the calendar: it was deleted in Calendar; the next sync creates it again.

Rehber

Yüklemeden ilk etkinliğe beş dakika.

1. Rowdate'i aç

Tabloda Uzantılar › Rowdate › Rowdate'i aç. İlk satır sütun adları olmalı, ör. Müşteri, Tarih, Saat, Süre.

2. Takvimi seç

Listede etkinlik ekleyebildiğin tüm takvimler var, ortak takvimler dahil.

3. Sütunları eşle

  • Etkinlik başlığı bir şablondur. + Sütun ekle ile {{Müşteri}} · {{Hizmet}} gibi başlıklar kur.
  • Tarih sütunu zorunlu. Gerçek tarihler, formül sonuçları ve 10.11.2026, 2026-11-10 gibi metinler çalışır.
  • Saat isteğe bağlı. Yoksa etkinlik tüm gün olur. Saat içeren tarih hücresi de olur.
  • Süre dakika (90), saat (1,5 saat) ya da 1:30. Varsayılan 60 dakika. İstersen Bitiş tarihi / Bitiş saati sütunu kullan.
  • Diğer alanlar: yer, açıklama (o da şablon), katılımcı e-postaları (virgülle), renk (1–11 ya da mavi, domates gibi ad), tekrar (günlük, haftalık, aylık, yıllık) ve isteğe bağlı tekrar sayısı, hatırlatma dakikası.
  • İptal sütunu: evet, x yaz ya da onay kutusunu işaretle; sonraki senkronda o satırın etkinliği silinir.

4. Aktar

Tüm satırları aktar ya da satırları seçip Seçili satırları aktar. Rowdate iki sütun ekler: Rowdate Event ID ve Rowdate Status. ID sütununa dokunma; satırı etkinliğe bağlayan odur. Değişmeyen satırlar sonraki seferde atlanır.

Canlı senkron (Pro)

Canlı senkron'u işaretle; o sayfada yaptığın her düzenleme birkaç saniyede etkinliğe yansır. Formüllerin ya da başka betiklerin yaptığı değişiklikler tetiklemez; onlar için normal senkron çalıştır.

Sık görülen mesajlar

  • Tarih anlaşılmadı: hücre okunabilir bir tarih değil. Sütunu tarih biçimine al ya da 10.11.2026 yaz.
  • Bitiş, başlangıçtan önce: bitiş saatini ya da süreyi kontrol et.
  • Bu takvime yazma iznin yok: takvim sahibinden "Etkinliklerde değişiklik yapma" izni iste ya da başka takvim seç.
  • Takvimde etkinlik bulunamadı: Takvim'de silinmiş; sonraki senkronda yeniden oluşur.
