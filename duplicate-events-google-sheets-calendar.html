Stop duplicate events when syncing Google Sheets to Calendar

Why it happens, how to clean up, and how to avoid it next time.

Why the duplicates appear

Most ways of getting rows into Google Calendar (CSV import, a quick script, simple add-ons) create events. They do not remember which event belongs to which row. So when you change a row and run the import again, the tool has no way to find the old event: it creates a new one, and the old one stays.

The same thing happens when the import runs on a schedule, when two people run it, or when a run fails halfway and you start it again.

Cleaning up the duplicates you already have

  • If everything came from one import into its own calendar, the quickest fix is to delete that calendar (Settings › the calendar › Remove calendar) and sync again into a fresh one.
  • If the events are mixed with others, search Google Calendar for a word from the titles, open the list view and delete the extra copies. There is no bulk "remove duplicates" button in Google Calendar.
  • Before you sync again, make sure the tool you use can update events, or you will be back here next week.

Syncing without duplicates

The reliable approach is to store the event ID next to each row. Then a re-run can do the right thing for every row:

  • No ID yet: create the event and write the ID into the row.
  • ID present and the row changed: update that event.
  • ID present and nothing changed: skip it.
  • Row marked cancelled: delete that event.

This is how Rowdate works. It adds two columns to your sheet, Rowdate Event ID and Rowdate Status, and uses the ID to update the same event every time. Running Sync twice in a row changes nothing the second time; every row just says "Unchanged".

If you write your own script, the same idea applies: see the script in our Sheets to Calendar guide and extend it to read the event by ID with CalendarApp.getEventById() and update its time and title.

Other things that look like duplicates

  • Events at the wrong time next to the right ones: a time zone mismatch between the spreadsheet (File › Settings) and the calendar. Make them the same.
  • Events on the wrong day: 11/10/2026 means 10 November in the US and 11 October in Europe. Use your spreadsheet's locale consistently, or write dates as 2026-11-10.
  • Recurring events multiplied: a "repeat weekly" row that is also listed once per week in the sheet. Use one or the other.
