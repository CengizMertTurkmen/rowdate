How to create Google Calendar events from Google Sheets

Three ways, from free and manual to fully synced. Updated November 2026.

You have bookings, classes, shifts or deadlines in a spreadsheet and you want them on a calendar. Google Sheets has no built-in "send to Calendar" button, so you have three options.

Option 1: Export a CSV and import it into Google Calendar

Free and needs no code, but it is a one-time copy.

  1. Rename your columns to the names Google Calendar expects: Subject, Start Date, Start Time, End Date, End Time, All Day Event, Description, Location.
  2. Dates must look like 11/10/2026 and times like 10:00 AM.
  3. In Sheets: File › Download › Comma-separated values (.csv).
  4. In Google Calendar: Settings › Import & export › Import, pick the file and the calendar.

The catch: nothing links the row to the event. If a time changes, you edit the event by hand, or import again and get a duplicate.

Option 2: A small Apps Script

Free, and it can remember which row made which event. Open Extensions › Apps Script, paste this, and run createEvents. The sheet needs columns A Title, B Start, C End (date and time in each cell) and an empty D Event ID.

function createEvents() {
  const sheet = SpreadsheetApp.getActiveSheet();
  const rows = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getDefaultCalendar();
  for (let i = 1; i < rows.length; i++) {
    const [title, start, end, eventId] = rows[i];
    if (!title || !start || !end || eventId) continue; // skip empty or already created rows
    const event = calendar.createEvent(title, new Date(start), new Date(end));
    sheet.getRange(i + 1, 4).setValue(event.getId());
  }
}

It works for a simple list. What it does not do, and what people usually end up adding:

  • Updates. Rows that already have an ID are skipped, so a changed time never reaches the calendar. You need to read the event back, compare and update it.
  • Cancellations. Deleting a row leaves the event behind.
  • Separate date and time columns, durations instead of end times, and text dates like 10.11.2026.
  • Time zones. A time-only cell is stored as a date in 1899, and old time zone offsets can shift it by minutes.
  • Errors. One bad cell stops the whole run.

Option 3: An add-on that keeps the sheet and calendar in sync

This is what Rowdate does. Open it from Extensions › Rowdate and:

  1. Pick a calendar, including shared calendars you can edit.
  2. Match your columns. Title is a template like {{Client}} · {{Service}}; date, time and duration can be separate columns; Rowdate guesses them from your headers.
  3. Click Sync all rows. Each row gets an event ID and a status. Change a row and sync again: the same event moves, nothing is duplicated. Write yes in a cancel column and the event is deleted.

Dates from formulas (=A2+7, =WORKDAY()) and imported data are read in your spreadsheet's time zone. A row that cannot be read gets a clear message such as "Date not recognised: 32.13.2026" and the other rows still sync.

Which one should you use?

  • A one-off list you will never change: CSV import.
  • You like code and the list is simple: the script above.
  • The sheet keeps changing (bookings, rosters, schedules) or other people edit it: a sync add-on.
