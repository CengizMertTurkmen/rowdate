# Rowdate — Google Sheets to Google Calendar sync

Rowdate is a Google Sheets add-on for turning spreadsheet rows into Google Calendar events. It creates events, updates linked events when a row changes, and removes them when a row is marked cancelled. Useful for appointments, bookings, classes, shifts and deadlines already managed in a sheet.

[Install from Google Workspace Marketplace](https://workspace.google.com/marketplace/app/rowdate/1047319266412) · [Website](https://rowdate.codeven.io/) · [Türkçe](https://rowdate.codeven.io/tr/)

## Get started

1. Install Rowdate, then open **Extensions → Rowdate → Open Rowdate** in Google Sheets.
2. Choose a calendar you can edit and map your title, date, time and duration columns.
3. Preview and sync. Keep the Rowdate Event ID column: it connects each row to its existing event.

You can start with the [sample CSV spreadsheet](https://rowdate.codeven.io/rowdate-sample.csv). Import it into Google Sheets and change the example dates and times before syncing.
