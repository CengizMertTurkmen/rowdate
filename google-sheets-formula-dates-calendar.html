Put calculated spreadsheet deadlines on Google Calendar

Formula dates and working days · Updated 22 November 2026

A delivery date plus five working days. A follow-up one week after an appointment. If your schedule already lives in Google Sheets, calculate those dates there and send the results to Google Calendar with Rowdate.

1. Give each deadline its own row

Start with columns for Task, Start date, Due date, Time and Duration. Enter a real start date in B2, for example =DATE(2026,12,4). Put the calculation in C2.

  • =B2+5 adds five calendar days.
  • =WORKDAY(B2,5) adds five working days, skipping Saturday and Sunday.
  • =WORKDAY(B2,5,Holidays!A2:A20) also skips the dates in a separate Holidays tab.

For Friday 4 December 2026, the first formula gives Wednesday 9 December. The second gives Friday 11 December. Your holiday list can move that deadline further.

Format the result column using Format › Number › Date. Some spreadsheet locales require semicolons between formula arguments. Google's WORKDAY reference explains its arguments and optional holiday range.

2. Map the calculated date in Rowdate

  1. Install Rowdate from Google Workspace Marketplace, then open Extensions › Rowdate › Open Rowdate.
  2. Choose a calendar you can edit. A separate test calendar is useful for the first few rows.
  3. Map the title to Task, the date to Due date, and the time and duration to their columns.
  4. Check the preview and click Sync all rows.

Rowdate reads the calculated value of a date-formatted cell using the spreadsheet's time zone. It does not send the formula text to Calendar. Keep the event ID and status columns Rowdate adds so later syncs can update the linked event.

3. Sync again after formulas change

Change a starting date, let Sheets finish calculating, then run Sync all rows again. Rowdate reads the new due dates and updates the linked events. Moving an event in Calendar does not change the formula in your sheet.

Live sync has a specific limit. Pro live sync responds to user edits on the mapped sheet and syncs the edited rows. A TODAY() recalculation at midnight, an API import, or a changed formula dependency on another row does not guarantee that the deadline row will sync. Run Sync all rows after those changes. Rowdate currently has no scheduled background polling for formula recalculations.

Google's installable trigger documentation explains why script executions and API requests do not trigger spreadsheet edit handlers.

If the event lands on the wrong day

  • Check the spreadsheet's time zone under File › Settings and compare it with the calendar's time zone.
  • Make sure the calculated cell contains a date, rather than a text string or an error such as #VALUE!.
  • Read the row's status message before trying again.
  • Keep each event ID attached to its row when sorting or moving data.
